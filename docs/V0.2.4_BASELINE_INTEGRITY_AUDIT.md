# v0.2.4 baseline-integrity audit

This audit defines the attribution boundary for the comparator implementations
used by the target-discovery-v1 evidence freeze.

## Findings

- The benchmark runner passes only the feature matrix and a seed into method
  fitting. Reference labels enter only after fitting, in evaluation. No label
  leakage was found.
- Every method receives the same preprocessed matrix within a dataset. The
  biological transform is protocol-declared arcsinh followed by median/MAD
  scaling.
- DBSCAN, HDBSCAN, and OPTICS use scikit-learn. The remaining entries are
  controlled benchmark implementations and must not be presented as authors'
  official software unless separately established.
- The artifact identifier `AMD-DBSCAN` is an AMD-inspired surrogate. It retains
  the dense pairwise Euclidean-distance stage described in the published method
  and authors' reference code, but replaces the subsequent stability search,
  adaptive MinPts, histogram clustering, and density-specific MinPts procedure
  with a benchmark-specific three-level extraction. It is therefore not an
  official-compatible AMD-DBSCAN port.
- Dense pairwise storage is faithful to that first AMD stage. In the canonical
  cytometry campaign, all 13 surrogate jobs failed before clustering because a
  float64 distance matrix would require 14.5 GiB to 1.14 TiB under the 8 GiB
  cap. Quality remains missing and the failures affect completion only.

## Submission policy

Reviewer-facing text and figures display this entry as **AMD-inspired**. Raw
CSV and protocol keys retain `AMD-DBSCAN` for immutable artifact identity. The
frozen source file is not rewritten after execution because its hash is part of
the run manifests; this audit supersedes the inaccurate "official-compatible"
wording in that frozen source snapshot.

A future faithful port requires a small-data equivalence suite against the
published Algorithms 1--3 and the authors' reference implementation. A
blockwise or streaming distance stage would be a new validated implementation,
not a transparent performance patch to the frozen surrogate.
