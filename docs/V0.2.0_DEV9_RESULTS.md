# StrataSCAN 0.2.0-dev9 implementation report

Status: experimental research implementation, not a public API replacement.
The public `StrataSCAN` alias and package version remain frozen at 0.1.2.

## Implemented optimization slice

`stratascan.optimization.OptimizationStrataSCAN` retains the 0.1.2 geometry:

- one sparse 32-neighbour graph;
- shell volumes at ranks 4, 8, 16, and 32;
- the predictive constrained multiscale Gamma mixture;
- strict-core components induced by the first four k-NN edges;
- explicit noise and border attachment only through existing graph edges.

Within every Gamma stratum, dev9 evaluates every observed `d4` activation
event. The selected prefix maximizes a description gain consisting of Gamma
signal/background log-odds, a Jeffreys Beta-Bernoulli topology Bayes factor,
and a universal threshold code. Component support is evaluated with neighbour
ranks 5--8, disjoint from ranks 1--4 used to construct connectivity. This
held-out edge window prevents a connected component from being rewarded for
the same edges that defined it. Retaining a component pays a `log(n)` root
code. Border/noise decisions use a fitted two-state Gaussian mixture on
`log(d(i,j) / d4(j))`, with Gamma gating when the inherited sparse-tail
guardrail is inactive.

The event sweep, component pass, and border pass use bounded-degree arrays and
sparse graphs. They require `O(nk)` memory and no dense `n x n` matrix.

## Magic-number status

Removed from the new dense extraction path:

- `q95(d4)` core threshold: replaced by an exact observed-event optimum;
- minimum component size 5: replaced by topology evidence and an MDL root
  code;
- border multiplier 1.25: replaced by an unlabeled fitted edge-ratio model;
- a posterior 0.5 core cutoff: replaced by complete Gamma log-odds in the
  objective.

Still intentionally frozen rather than claimed as solved:

- `k=32` and shells `(4, 8, 16, 32)`, to isolate extraction changes;
- the 0.1.2 sparse-tail probe, retained as a guardrail because the unified
  background-stratum null is not yet reliable;
- four connectivity edges and the equal-width held-out ranks 5--8;
- the existing predictive Gamma-mixture fitting controls.

Thus dev9 is Slice A/B/C infrastructure, not yet the final magic-number-free
0.2.0 objective.

## Frozen regression results

All comparisons are paired against 0.1.2 and use no labels for fitting or
parameter selection.

### Synthetic quality

Protocol: seven families, `n=5,000`, seeds 23, 42, and 73 (21 paired cases).
The reproducible matrix is
`benchmarks/protocol.optimization-v0.2.0-dev9.json`.

- mean delta macro target F1: **+0.03194**;
- median delta macro target F1: **0.00000**;
- mean delta pairwise F1: **+0.02763**;
- mean delta noise F1: **-0.00821**;
- 9 wins, 4 exact ties, and 8 losses in macro target F1;
- worst macro target F1 regression: **-0.00874**;
- median runtime ratio: **0.926x**;
- mean peak-RSS delta: **+1.45 MB**.

The largest mean gains are Gaussian overlap 8D (+0.1622 macro F1) and rings
2D (+0.0575). The consistent regression is moons 2D (-0.0048 mean macro F1
and -0.0255 mean noise F1).

Evidence: `results/runs/optimization_v020_dev9_synthetic/results.csv`.

### Cytometry

On Levine, dev9 is close to 0.1.2: macro target F1 changes from 0.05470 to
0.05552, signal recall from 0.88218 to 0.88237, and the number of clusters from
32 to 38. This fixes an earlier prototype failure that produced hundreds of
micro-components.

Nilsson is nearly neutral in target F1 (-0.00105), with signal recall down
0.01955. Mosmann remains a clear failure: background rejection increases by
0.10891, but already-low signal recall falls from 0.06422 to 0.00917. The next
border/noise likelihood must address this trade-off without label tuning.

Evidence: `results/runs/optimization_v020_dev9_cytometry/results.csv`.

### Gaia transfer

Across 24 deterministically selected fields, mean best-cluster F1 changes by
**-0.02633**: 3 wins, 7 ties, and 14 losses; the worst field changes by
-0.1284. Median runtime is 0.996x and mean peak-RSS delta is +1.93 MB. The
regression is dominated by conservative border/noise assignments, so dev9
must not replace 0.1.2.

Evidence: `results/runs/optimization_v020_dev9_gaia/results.csv`.

### Scaling

The paired moons smoke test completes at one million observations:

| n | method | runtime, s | peak RSS, MB | macro target F1 |
| ---: | --- | ---: | ---: | ---: |
| 100,000 | 0.1.2 | 17.46 | 338.34 | 0.98542 |
| 100,000 | dev9 | 18.92 | 336.11 | 0.97913 |
| 1,000,000 | 0.1.2 | 41.47 | 1230.30 | 0.98742 |
| 1,000,000 | dev9 | 42.30 | 1215.49 | 0.98101 |

This verifies that the optimization layer preserves the sparse scaling order;
it does not yet satisfy the final five-million-point release gate on its own.

Protocol: `benchmarks/protocol.optimization-v0.2.0-dev9-scaling.json`.
Evidence: `results/runs/optimization_v020_dev9_scaling/results.csv`.

## Decision

Keep dev9 opt-in for objective research and ablations. Do not promote it to
the public estimator. The next bounded task is to replace the two-state border
heuristic with a properly coded predictive attach-versus-background model,
then rerun the already frozen synthetic, cytometry, and Gaia matrices before
working on adaptive `k` or shell selection.
