# v0.2.4 research-extension status

## Global contamination at fixed local difficulty

The new protocol fixes three target populations, 1,200 signal observations,
target geometry, and local background intensity. Increasing the declared
noise fraction from 25% to 99% expands only remote background support.

- Protocol: `benchmarks/protocol.v0.2.4-target-discovery-v1-global-contamination.json`
- Design and results: `docs/global-contamination-invariance.md`
- Completed StrataSCAN matrix: 30/30 successful cells
- Minimum target F1 over all cells: 0.907
- Minimum target discovery rate over all cells: 1.000
- Minimum known-noise F1 over all cells: 0.831

This supports global-contamination invariance for the declared construction.
It does not replace the existing fixed-support noise sweep, which increases
local contamination and exposes genuine failure at extreme noise.

## Strong density contrast

The new family fixes six equal-mass targets, separation, and 25% uniform
background while varying analytic Gaussian peak density by 16x, 64x, and
256x. It covers 2D and 8D isotropic cases plus determinant-preserving rotated
anisotropic cases.

- Protocol: `benchmarks/protocol.v0.2.4-density-contrast.json`
- Design and results: `docs/V0.2.4_DENSITY_CONTRAST_BENCHMARK.md`
- Completed StrataSCAN slice: 27/27 successful cells
- Discovery rate: 1.000 in every cell
- Case-median target F1 range: 0.829--0.929
- Worst retained single-cell target F1: 0.713
- Median candidate burden: 18 predicted clusters for six matched targets

The full 243-job, nine-method comparison is specified but has not been run.
No comparative density-scaling claim is therefore permitted yet.

The cluster package profiles the current default, screens nine challengers
without reference labels, freezes one deterministic choice, and only then
evaluates current-default versus frozen-choice performance on disjoint fresh
synthetic and cytometry holdouts.
