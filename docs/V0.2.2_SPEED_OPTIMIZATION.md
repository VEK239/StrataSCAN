# v0.2.2 speed optimization validation

## Changes

The release estimator keeps two deterministic starts per Gamma candidate: a
split warm start and an independent density-quantile start.  The implementation
now normalizes the Gamma E-step in place and uses safeguarded Newton updates
for the constrained log-rate slope.  The Newton solver retains a bracketed
bisection fallback, so it solves the same likelihood equation as the former
fixed-step bisection loop.

The default number of starts changed from three to two.  A one-start experiment
was rejected: it substantially reduced quality on the overlapping-density case
with seed 251.  The second independent start is therefore retained as a
quality safeguard.

## Initialization sensitivity check

The one-start configuration was tested separately on the same seven families
at seeds 42 and 251.  It regressed on overlapping-density seed 251: macro
target F1 fell from 0.488304 to 0.177521, noise F1 from 0.917205 to 0.898028,
and pairwise F1 from 0.309713 to 0.078695.  It is not a released default.

## Automated validation

`python -m pytest` completed with 52 passing tests.  The suite includes a
numerical equivalence test comparing the in-place E-step with SciPy's stable
`logsumexp`, and verifies the constrained slope equation directly.
